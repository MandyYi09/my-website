# Publishing

The portfolio is deployed from `main` at https://mandyyi09.github.io/my-website/.

Full project experiences load their own canonical GitHub Pages websites. The historical zhong-art-project, align-studio-project, sportx-project and little-mandy entry pages redirect to those sites, so old bookmarks also receive the current version. Preview-only visual assets and the model module used by About remain local to the portfolio.

Edit the source repository for each project, push its main branch, and confirm its deployment. Do not patch a compiled bundle inside this portfolio to change an application.
