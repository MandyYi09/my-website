Design notesModern Shuilu · Returning without an account

I wanted visitors to start looking at the paintings straight away. Instead of putting registration before exploration, I used a daily encounter and a locally saved viewing path to give people a way to return.

01 / A daily encounter

One figure for each day

The draw converts the device’s time to a date in Beijing time and selects a figure from a fixed rotation. Reopening or refreshing reveals the same figure that day; everyone shares that day’s card.

This creates a daily rhythm. It does not track whether an individual has drawn already: visitors can reveal the card again, but the result stays the same.

02 / A personal viewing path

Keep a detail, come back to it

When a visitor saves a detail, Path stores the painting ID, the chosen detail—headwear, hands or clothing—and any attached note in the browser’s localStorage. It saves these references rather than image files.

On the next visit in the same browser, the site reads those records and rebuilds the collection. Closing the page normally does not erase it.

Notice a detail→Save it to Path→Return in the same browser→Continue exploring

The tradeoff

This lets visitors begin without creating an account. The collection belongs to that browser profile, not a signed-in identity: it does not sync across devices or browsers, clearing site data removes it, and private browsing normally keeps it only for that session. Cross-device continuity would need a separate sync or export feature.
