# Live project covers

Walker uses the original sketch from MandyYi09/walker. Glitch and Shapes use the local project sketches. The p5 runtime is shared with Circle Multiplication; the adapter limits thumbnail rendering to 30 fps and removes page margins.

The 3D Shuilu experiment preview renders the original local guardian geometry and reference texture. Website previews load the actual portfolio homepage (pinned to Walker) or Modern Shuilu Atlas in a scaled desktop viewport. No camera is enabled by any cover.

Covers notify the gallery only after rendering; still images remain as fallbacks. The gallery unloads offscreen frames and pauses all covers when a dialog opens, the tab is hidden, or the viewer pauses animation.
