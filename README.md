# My Personal Website

I originally built this website by hand, writing the HTML, CSS, and JavaScript myself. It started as a way to learn web development and create a personal space for my projects, photography, and interests.

The website brings together my creative coding experiments, sports, photography, and a little about me.

[Visit my website](https://mandyyi09.github.io/my-website/)

## Building the Website

The website has grown through several rounds of changes:

1. **Building the foundation:** I started with individual HTML pages, CSS styles, and JavaScript interactions to organize and present my work.
2. **Adding content:** I brought together my coding projects, photographs, and experiences in tennis and rowing, with dedicated pages for Projects, Sports, Photography, and About.
3. **Making it interactive:** I added live project previews, a homepage slideshow, and an animated 3D version of myself to make the website more playful and personal.
4. **Refining the experience:** I continued adjusting the navigation, page structure, spacing, and visual style as the website developed.

The site uses HTML, CSS, and JavaScript, with libraries supporting features such as slideshows, photo galleries, and 3D experiences. It is hosted on GitHub Pages.
