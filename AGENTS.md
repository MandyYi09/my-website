# Project naming and copy

When the user renames a project, update the project name everywhere it appears, including narrative copy on About, Sports, and other pages, project cards, project detail views, metadata, captions, and accessibility labels. Search both the former name and spelling/spacing variants. Preserve ordinary uses of the same words that do not refer to the project.

After completing a rename, explicitly remind the user in the final response to check that project mentions in the written content have also been updated. This is a standing user request.
